# A.OEA Professional Portfolio Website

A modern, creative, and fully responsive professional portfolio website showcasing frontend development, graphic design, digital art, and trading expertise.

## 🌟 Features

### Main Portfolio (portfolio.html)
- **Stunning Hero Section**: Eye-catching animated introduction with gradient text and smooth scroll navigation
- **About Section**: Professional introduction highlighting skills and expertise
- **Skills Showcase**: Interactive grid display of 12+ professional competencies with hover effects
- **Projects Portfolio**: Showcase of 6 major project categories with descriptions and images
- **Contact Section**: Professional contact information with CV download option
- **Social Media Integration**: Direct links to all major social platforms (Facebook, Instagram, X, LinkedIn, GitHub, TikTok, YouTube)
- **Back-to-Top Button**: Smooth scroll functionality for better UX
- **Responsive Design**: Mobile-optimized for all screen sizes

### Authentication Pages

#### Professional Login Page (login.html)
- Modern gradient background with animated backdrop
- Centered card design with logo integration
- Form fields with focus states and validation feedback
- "Remember me" checkbox and "Forgot password" link
- Comprehensive social media links section
- Smooth animations and transitions
- Mobile-responsive layout
- Professional typography with gradient heading

#### Professional Signup Page (signup.html)
- Matching design aesthetic with login page
- Multi-field form with proper labels
- Password requirement guidelines
- Password confirmation validation
- Form validation with visual feedback
- Social media connection options
- Links to existing accounts
- Professional styling and accessibility features
